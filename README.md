# ExportIQ — AI Export Documentation Assistant

A responsive front-end prototype built with **HTML, CSS, and vanilla JavaScript**.

## Files
- `index.html` — page structure and content
- `styles.css` — layout, colors, responsive design, and styling
- `script.js` — navigation, shipment wizard, document previews, verification, and checklist interactions

## Run locally
Keep all files in the same folder and open `index.html` in a modern web browser. No installation or build tools are required.

## Upload to GitHub
Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the root of your GitHub repository.

## Prototype limitations
This is a front-end demo. It does not yet connect to a real AI model, backend, database, OCR service, customs platform, or live regulatory data. Demo data is held in browser memory and resets when the page is refreshed. Generated documents and compliance checklists are drafts and must be checked against official requirements.
